# Publishing Checklist

Use this before submitting the Codex for Open Source application.

## Repository

- [ ] Repository is public on GitHub.
- [ ] GitHub profile is public.
- [ ] `README.md` is visible and accurate.
- [ ] `LICENSE` is present.
- [ ] `CONTRIBUTING.md` is present.
- [ ] `SECURITY.md` is present.
- [ ] Local cache files are ignored.
- [ ] Unrelated workspace folders are ignored.

## Verification

- [ ] `npm run typecheck`
- [ ] `npm run build`
- [ ] App opens locally.
- [ ] Dashboard screenshot is captured.
- [ ] Script generation workflow is captured.

## Application

- [ ] GitHub repository URL is filled in.
- [ ] OpenAI Organization ID is filled in.
- [ ] Role is set to main maintainer or core maintainer.
- [ ] Repository importance text is under 500 Japanese characters.
- [ ] API credit usage text is under 500 Japanese characters.
- [ ] Additional notes are under 500 Japanese characters.
